# Agent Operations Assistant

<p align="center">
  <strong>Built and maintained by a single developer</strong><br>
  Supporting 100+ weekly users<br>
  Powered by Google Apps Script and Google Workspace
</p>

A workforce support assistant designed to automate documentation, email generation, chat responses, and daily operational workflows.

---

## Overview

Agent Operations Assistant is a Google Apps Script based productivity platform developed to help support agents handle customer interactions more efficiently and consistently.

The application combines several operational tools into a single interface, reducing repetitive manual tasks, improving documentation quality, and accelerating daily workflows.

## Architecture

```text
Support Agents
        │
        ▼
Agent Operations Assistant
        │
        ├── Comment Assistant
        ├── Email Assistant
        ├── Chat Assistant
        ├── Timer Utilities
        ├── Feedback System
        │
        ▼
Google Apps Script
        │
        ▼
Google Sheets Repository
```

### Core Modules

#### Comment Assistant

Tools for interaction logging, documentation generation, timers, and workflow tracking.

#### Email Assistant

Template-based email generation with dynamic content and reusable canned responses.

#### Chat Assistant

A searchable canned-response system with quick insertion and management capabilities.

#### Feedback System

Allows users to submit suggestions and help guide future improvements.

#### Data Repository

Google Sheets serves as a lightweight backend for template storage, feedback collection, and knowledge management.
